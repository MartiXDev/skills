# Templates

Templates are opt-in starting points. Review repository tooling, policy,
permissions, and rollback behavior before installing or copying any template.

- `hooks/` contains bounded native launcher examples.
- `martix-git.json` contains the disabled-by-default repository policy template.
- `ci/` contains commit-policy validation examples.
- `github/` contains PR and merged-event guidance.
- `release-verify.md` contains a verify-before-publish checklist.
