# Documentation policy

This folder contains normative repository policy and the source registry that
supports it. Policy is enforceable guidance; dated evidence belongs in
`docs/knowledge/`.

| Document | Purpose |
| --- | --- |
| [Custom AI artifact rules](./custom-ai-artifact-rules.md) | Canonical rules for skills, plugins, instructions, prompts, agents, hooks, MCP/LSP configuration, metadata, evals, templates, and validation. |
| [Custom AI artifact resources](./custom-ai-artifact-resources.md) | Primary upstream links used to review or refresh the rules. |

Keep decisions in the rules document and source discovery links in the resource
index. Do not create another policy copy under `docs/`.
