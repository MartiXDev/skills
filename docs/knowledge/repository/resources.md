# Repository research resources

This is the seed registry for repository-architecture and maintenance research.
It was assembled from the documentation architecture review on 2026-07-25;
re-check volatile pages before promoting new conclusions into policy.

| Source | Use |
| --- | --- |
| [Diátaxis](https://diataxis.fr/) | Separate tutorials, how-to guides, reference, and explanation. |
| [Microsoft Learn: organize documentation](https://learn.microsoft.com/en-us/contribute/content/prose-and_style/subheadings) | Information architecture and navigational writing guidance. |
| [W3C Data on the Web Best Practices](https://www.w3.org/TR/dwbp/) | Metadata, provenance, and discoverability principles. |
| [GitHub Docs: CODEOWNERS](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners) | Ownership and review routing. |
| [GitHub Docs: linking to releases](https://docs.github.com/en/repositories/releasing-projects-on-github/linking-to-releases) | Versioned-source and freshness considerations. |
| [JSON Schema](https://json-schema.org/) | Machine-readable metadata and validation conventions. |
| [markdownlint](https://github.com/DavidAnson/markdownlint) | Markdown consistency checks. |
| [lychee](https://github.com/lycheeverse/lychee) | Link validation strategy. |
