# AI Knowledge Map

This directory contains research notes, source lists, and working guidance for
AI-assisted development. Start with the topic that matches the task; resource
files collect primary links, while research and strategy files contain the
current synthesis.

- [Best practices](#best-practices): usage, context, security, latency, and
  cost guidance.
- [Hooks](#hooks): lifecycle automation resources.
- [LLM](#llm): model selection, prompt caching, cost, and session research.
- [Plugins](#plugins): plugin documentation resources.
- [Skills](#skills): Agent Skills research and resource links.
- [Tools](#tools): broader AI development environment design.
