# Rule section contract

Use this contract for every rule in this package so agents can open one
decision guide without loading the whole knowledge base.

## Section order

1. `## Purpose`
2. `## Default guidance`
3. `## Avoid`
4. `## Review checklist`
5. `## Related files`
6. `## Source anchors`

Keep each rule narrow. Explain why the default protects the Platform boundary,
then link to the next rule instead of duplicating its content.
